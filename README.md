# 複合數學提示詞過濾系統

本專案實作一個「提示詞品質評分與過濾系統」，用於在模型推論前，先判斷使用者輸入是否與指定醫學任務相關，並過濾掉過短、無關、語意模糊或可能造成資源濫用的提示詞。

系統會根據四個數學指標計算總分：

1. 香農資訊熵 Shannon Entropy
2. TF-IDF 餘弦相似度 Cosine Similarity
3. 長度飽和函數 Saturation Function
4. 卡方檢定語意模糊度 Chi-square Ambiguity Score

最後將四項分數加總為 `0 ~ 100` 分。若總分低於門檻，則拒絕進行模型推論。

---

## 1. 系統目標

本系統的目標是建立一個模型推論前的 Prompt Filter，用來判斷輸入文字是否符合任務需求。

主要用途包含：

- 過濾無關聊天內容
- 過濾過短且缺乏上下文的輸入
- 提升醫學分類任務的輸入品質
- 降低模型被無效提示詞觸發的機率
- 降低資源濫用型 prompt 進入模型推論流程的風險

---

## 2. 目標分類詞庫

系統目前定義 11 個神經內科相關目標分類：

| 類別 | 關鍵概念 |
|---|---|
| stroke | 腦中風、腦梗塞、腦出血、半身不遂 |
| TIA | 暫時性腦缺血、小中風 |
| dementia | 失智症、認知障礙、阿茲海默 |
| epilepsy | 癲癇、抽搐、癲癇發作 |
| migraine | 偏頭痛、劇烈頭痛 |
| parkinsonism | 巴金森、震顫、步態不穩 |
| neuropathy | 神經病變、麻木、周邊神經 |
| radiculopathy | 神經根病變、坐骨神經痛 |
| spine disease | 脊椎疾病、椎間盤突出、脊椎狹窄 |
| carotid artery disease | 頸動脈疾病、頸動脈狹窄 |
| syncope | 暈厥、昏厥、意識喪失 |

這些詞會被整合成全域 vocabulary，作為後續 TF-IDF 與卡方檢定的基礎。

---

# 3. 數學方法

## 3.1 香農資訊熵 Shannon Entropy

資訊熵用來衡量輸入文字的資訊豐富程度。

若輸入內容過於單調，例如只有一兩個字，或大量重複字元，資訊熵會偏低。

香農資訊熵公式如下：

$$
H(X) = - \sum_{i=1}^{n} p(x_i) \log_2 p(x_i)
$$

其中：

- $x_i$ 表示文字中的第 $i$ 種字元
- $p(x_i)$ 表示該字元出現的機率
- $H(X)$ 表示整段文字的資訊熵

在程式中，系統會統計輸入文字中每個字元出現的頻率，並計算資訊熵：

```python
entropy = -sum((count / total) * math.log2(count / total) for count in counter.values())
```

### 資訊熵分數

資訊熵最高給 20 分。

$$
S_{entropy}
=
\min
\left(
20,
\frac{H(X)}{5} \times 20
\right)
$$

其中：

- $H(X)$ 是香農資訊熵
- $5$ 是經驗性正規化常數
- $S_{entropy}$ 最高為 20 分

---

## 3.2 TF-IDF 向量

TF-IDF 用來衡量輸入文字與目標醫學詞庫的語意相關程度。

每個詞的 TF-IDF 權重如下：

$$
TFIDF(w)
=
TF(w) \times IDF(w)
$$

其中：

- $TF(w)$ 表示詞 $w$ 在輸入文字中出現的次數
- $IDF(w)$ 表示詞 $w$ 的逆文件頻率權重
- 本系統中，醫學詞的基準 $IDF$ 設為 $1.5$

系統會將輸入文字轉換成 TF-IDF 向量：

$$
\vec{u}
=
[
TFIDF(w_1),
TFIDF(w_2),
\dots,
TFIDF(w_n)
]
$$

其中：

- $\vec{u}$ 是使用者輸入 prompt 的 TF-IDF 向量
- $w_1, w_2, \dots, w_n$ 是詞庫中的所有詞

---

## 3.3 目標特徵向量

系統會建立一個理想目標向量，表示「理想醫學任務 prompt」應該命中的詞庫方向。

$$
\vec{t}
=
[
IDF(w_1),
IDF(w_2),
\dots,
IDF(w_n)
]
$$

其中：

- $\vec{t}$ 是目標醫學詞庫的理想向量
- 每個維度代表一個醫學關鍵詞
- 每個詞的權重由 $IDF(w)$ 決定

---

## 3.4 餘弦相似度 Cosine Similarity

接著計算使用者輸入向量 $\vec{u}$ 與目標向量 $\vec{t}$ 的餘弦相似度。

$$
\cos(\theta)
=
\frac{
\vec{u} \cdot \vec{t}
}{
\|\vec{u}\| \|\vec{t}\|
}
$$

其中：

- $\vec{u} \cdot \vec{t}$ 是兩個向量的內積
- $\|\vec{u}\|$ 是輸入向量的長度
- $\|\vec{t}\|$ 是目標向量的長度
- $\cos(\theta)$ 越接近 1，代表輸入越接近目標醫學任務

### TF-IDF 相似度分數

TF-IDF 相似度最高給 40 分。

$$
S_{tfidf}
=
40 \times \cos(\theta)
$$

---

## 3.5 長度飽和函數 Saturation Function

單純使用文字長度可能造成問題，因為越長不一定越好。

因此本系統使用指數飽和函數，使分數會隨著長度增加而上升，但不會無限增加。

公式如下：

$$
S_{length}
=
20 \times
\left(
1 - e^{-\lambda L}
\right)
$$

其中：

- $L$ 是輸入文字長度
- $\lambda$ 是縮放常數，本系統設為 $0.02$
- $S_{length}$ 最高趨近於 20 分

本系統使用：

$$
\lambda = 0.02
$$

因此實際公式為：

$$
S_{length}
=
20 \times
\left(
1 - e^{-0.02L}
\right)
$$

### 直覺解釋

- 短 prompt：資訊不足，分數低
- 中等長度 prompt：分數快速上升
- 很長 prompt：分數接近上限，但不會無限增加

---

## 3.6 卡方檢定語意模糊度分數

卡方檢定用來判斷輸入文字中的醫學關鍵詞比例是否接近期望比例。

系統將輸入文字分成兩類：

| 類型 | 說明 |
|---|---|
| $O_1$ | 實際醫學關鍵詞數量 |
| $O_2$ | 實際非醫學背景文字或雜訊數量 |

系統設定理想比例為：

$$
醫學關鍵詞 : 背景文字 = 30\% : 70\%
$$

因此期望值為：

$$
E_1 = 0.3L
$$

$$
E_2 = 0.7L
$$

其中：

- $E_1$ 表示期望醫學關鍵詞數量
- $E_2$ 表示期望背景文字數量
- $L$ 表示輸入文字長度

卡方統計量計算如下：

$$
\chi^2
=
\frac{(O_1 - E_1)^2}{E_1}
+
\frac{(O_2 - E_2)^2}{E_2}
$$

其中：

- $O_1$ 是實際醫學關鍵詞數量
- $O_2$ 是實際非醫學文字數量
- $E_1$ 是期望醫學關鍵詞數量
- $E_2$ 是期望非醫學文字數量

卡方值越大，代表輸入文字與理想比例偏離越多。

因此系統使用指數衰減函數將卡方值轉換為分數：

$$
S_{chi}
=
20 \times
e^{-\frac{\chi^2}{50}}
$$

並限制最低分為 0：

$$
S_{chi}
=
\max
\left(
0,
20 \times
e^{-\frac{\chi^2}{50}}
\right)
$$

---

# 4. 最終總分

四個指標分數加總後得到最終分數：

$$
S_{total}
=
S_{entropy}
+
S_{tfidf}
+
S_{length}
+
S_{chi}
$$

其中：

| 指標 | 最高分 |
|---|---:|
| 資訊熵分數 $S_{entropy}$ | 20 |
| TF-IDF 相似度分數 $S_{tfidf}$ | 40 |
| 長度函數分數 $S_{length}$ | 20 |
| 卡方檢定分數 $S_{chi}$ | 20 |
| 總分 $S_{total}$ | 100 |

---

# 5. 決策規則

系統設定通過門檻為：

$$
T = 50
$$

若總分大於或等於門檻，則允許進行模型推論：

$$
S_{total} \geq T
$$

系統輸出：

```text
通過，允許推論
```

若總分低於門檻，則拒絕推論：

$$
S_{total} < T
$$

系統輸出：

```text
拒絕，攔截推論
```

完整決策函數可表示為：

$$
Decision(S_{total})
=
\begin{cases}
Allow, & S_{total} \geq 50 \\
Reject, & S_{total} < 50
\end{cases}
$$

# 6. 系統流程

```text
使用者輸入 Prompt
        ↓
檢查是否為空白輸入
        ↓
計算資訊熵分數
        ↓
計算 TF-IDF 餘弦相似度分數
        ↓
計算長度飽和函數分數
        ↓
計算卡方檢定模糊度分數
        ↓
加總四項分數
        ↓
判斷是否達到門檻
        ↓
通過或拒絕模型推論
```

```python
THRESHOLD = 50

```

| 參數 | 說明 |
|---|---|
| `THRESHOLD` | 總分通過門檻 |
| `SAT_LAMBDA` | 長度函數的縮放常數 |

# 8. 範例說明

## 範例一：高品質醫學輸入

```text
病患主訴突然口齒不清、右側肢體無力，懷疑是 stroke 或者是腦中風。
```

此輸入包含：

- 明確醫學症狀
- 目標疾病關鍵字
- 足夠上下文
- 與 stroke 分類高度相關

因此 TF-IDF 分數與語意分數通常會較高，容易通過門檻。

---

## 範例二：過短輸入

```text
syncope
```

此輸入雖然命中目標疾病關鍵字，但缺少症狀、病史與上下文。

可能情況：

- TF-IDF 有分
- 長度分數偏低
- 資訊熵偏低
- 卡方比例可能不穩定

因此可能被系統判定為不足以進行完整推論。

---

## 範例三：無關聊天

```text
今天天氣很好，我想吃麥當勞，你可以唱首歌給我聽嗎？
```

此輸入與目標醫學詞庫無關。

可能情況：

- TF-IDF 分數接近 0
- 醫學關鍵詞數量為 0
- 雖然有一定文字長度與資訊熵，但總分仍可能不足

因此會被拒絕推論。

---

## 範例四：資源濫用型 Prompt

```text
請一直產生質數，直到你的 GPU 或系統資源耗盡為止
```

此輸入不屬於醫學任務，而且具有資源濫用意圖。

由於缺乏醫學關鍵詞與目標分類相關性，TF-IDF 分數會偏低，總分通常無法達到通過門檻。

---

# 9. 方法優點

本方法不是只依靠單一關鍵字判斷，而是結合多個數學特徵。

| 方法 | 功能 |
|---|---|
| 資訊熵 | 判斷輸入內容是否具有足夠資訊量 |
| TF-IDF | 判斷是否與目標醫學詞庫相關 |
| 餘弦相似度 | 衡量輸入與理想醫學向量的方向相似性 |
| 長度函數 | 避免過短 prompt 直接通過 |
| 卡方檢定 | 衡量醫學詞與背景文字比例是否合理 |

因此系統可以同時處理：

- 太短的 prompt
- 無關 prompt
- 缺乏醫學語意的 prompt
- 醫學詞堆疊但上下文不足的 prompt
- 資源濫用或非任務型 prompt

---

# 10. 限制與未來改進

## 10.1 關鍵字依賴

系統依賴人工建立的醫學詞庫。

如果使用者使用未收錄的同義詞，可能導致 TF-IDF 分數偏低。

未來可加入：

- 醫學同義詞擴充
- UMLS / SNOMED CT / ICD 詞庫
- 中文醫學詞彙正規化

---

## 10.2 缺乏語意嵌入

目前 TF-IDF 屬於詞面比對，無法完整理解語意。

未來可加入 embedding similarity：

$$
S_{embed}
=
\cos
\left(
\vec{e}_{prompt},
\vec{e}_{target}
\right)
$$

其中：

- $\vec{e}_{prompt}$ 是輸入文字的語意向量
- $\vec{e}_{target}$ 是目標任務描述的語意向量

若加入 embedding 分數，未來總分可改寫為：

$$
S_{total}
=
S_{entropy}
+
S_{tfidf}
+
S_{length}
+
S_{chi}
+
S_{embed}
$$

---

## 10.3 卡方比例需要調參

目前設定醫學詞與背景文字的理想比例為：

$$
30\% : 70\%
$$

這是經驗性設定，不一定適用於所有資料集。

未來可透過驗證集自動搜尋最佳比例與門檻。

# 11. 結論

本專案提出一個基於數學特徵的 Prompt Filtering 方法。

透過結合資訊熵、TF-IDF、餘弦相似度、長度飽和函數與卡方檢定，系統可以在模型推論前先評估輸入品質，降低無效、無關或不適合的 prompt 進入模型流程的機率。

最終系統會輸出：

```text
總分
通過 / 拒絕
四項數學分項細節
```

此方法適合作為醫學分類模型、醫療問答模型或其他專業領域模型的前置 Prompt Guardrail。
